# 🌗 Light/Dark Mode Toggle – React

A guided React exercise (omardeangelis's course) to practice implementing a light/dark mode toggle using `useState` and `useEffect`.

## ✨ Features

-  Toggle between light mode and dark mode.
-  Update the interface based on the selected theme.
-  Practice managing component state and side effects in React.
